# Методы машинного обучения (MLM)

Данный репозиторий содержит лабораторные работы по дисциплине «Методы машинного обучения» (Вариант 14).

---

##  Список лабораторных работ

* **[Lab 1](Lab1.ipynb) — Основы Python**
  Базовые конструкции языка Python, алгоритмические задачи (обработка чисел, списков, строк и словарей).

* **[Lab 2](Lab2.ipynb) — Разведочный анализ данных (EDA)**
  Первичный анализ и предобработка датасета цен на автомобили (`CarPrice_Assignment.csv`): обработка пропусков и дубликатов, анализ распределений и выбросов, корреляционный анализ, кодирование категориальных признаков и масштабирование (`StandardScaler`, `MinMaxScaler`).

* **[Lab 3](Lab3.ipynb) — Градиентный спуск и регуляризация**
  Реализация алгоритма градиентного спуска с $L_1$-регуляризацией (Lasso-регрессия), визуализация сходимости функции потерь и сравнение с библиотечной реализацией из `scikit-learn`.

* **[Lab 4](Lab4.ipynb) — Бинарная классификация**
  Решение задачи классификации на датасете здорового питания (`healthy_meal_plans.csv`): очистка данных, One-Hot кодирование, стандартизация, обучение и оценка моделей **Logistic Regression**, **SVM** и **CART** в условиях дисбаланса классов, расчет метрик (Accuracy, Precision, Recall, F1, ROC-AUC), построение матриц ошибок и ROC-кривых.

* **[Lab 5](Lab5.ipynb) — Деревья решений (CART)**
  Реализация алгоритма бинарного дерева решений с нуля: расчет критерия неопределенности Джини (`gini`), прироста информации (`gain`), реализация критериев останова (`max_depth`, `min_samples_leaf`, чистота узла), функция точности (`accuracy_metric`) и валидация со строгим $100\%$ совпадением результатов с `DecisionTreeClassifier` из `scikit-learn`.

## 📂 Используемые датасеты

* `CarPrice_Assignment.csv` — характеристики и цены автомобилей для задач регрессионного и разведочного анализа (ЛР2).
* `healthy_meal_plans.csv` — пищевая ценность, ингредиенты и диетические флаги блюд с целевой бинарной переменной `is_healthy` (ЛР4).
